# Herdr Work

面向 AI 编程的 Herdr Agent 工作台，将任务、Agent 会话、文件与 Git、代码审查连接为连续的工作流程。

## 功能方向

- **任务管理**：分派任务、跟踪执行进度，关联工作区与执行 Agent。
- **Agent 协作**：定位任务对应的 Agent 会话，查看执行状态并衔接后续操作。
- **文件与 Git**：浏览项目文件、查看代码改动，处理暂存与提交。
- **代码审查**：阅读 Diff、添加行级反馈，将审查意见交回对应 Agent。
- **工作台体验**：统一导航、布局与快捷键，让任务、代码和审查共享工作上下文。

## 项目声明

- 本项目正在开发，以上为规划功能，目前尚无可安装的工作台版本。
- 本项目为独立社区项目，与 Herdr 及下列参考项目不存在官方隶属或背书关系。
