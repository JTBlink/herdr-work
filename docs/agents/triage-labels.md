# Triage Labels

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可由 Agent 承接；仍须满足阻塞依赖 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不安排处理 |
