# Sidebar 可迁移能力贯通与紧凑工作台布局

## 用户目标

复用已导入的 Sidebar 业务代码，把存在于源码中的能力贯通到 HerdrWork 的实际入口，完成所有本轮任务、自测、提交并发布。采用 VS Code 风格紧凑顶部：左视图标题和右内容标签同一行，移除独占一行的产品名和完整路径，底部显示简短工作目录/分支状态。

本轮范围来自 Sidebar 能力盘点：所有可迁移的日常文件、搜索、编辑、Git、预览与交互链路。宿主 pane 接管、独立插件安装更新、旧名称兼容不迁移；宿主多窗格/自动跟随 cwd 保持既有待定产品选择，不在本轮擅自开启。完整九模块目录整合仍由原 #17 跟踪。

4. 文件/Git 写入沿用目录实例、路径、HEAD/index/content 与确认保护；Unknown 通过现有显式核对接口恢复，不盲目重试。
5. UI 和状态只使用 HerdrWork 自己的配置与资料。Linux/Windows 走固定 SHA CI；Windows 无 Unix 任务 worker。

## 用户可观察验收

- 搜索/Quick Open 实时生效；点击命中行定位正确；File History 跟随当前文件，Show Changes 显示完整 patch。
- 原编辑器滚轮可用；无编辑时磁盘变化自动重载，有未保存内容时保留；保存冲突提供继续、重载、明确覆盖操作。
- 文件/Git/预览外部修改自动更新，手动刷新也更新当前预览；后台刷新不抢走焦点、不重置滚动、草稿或编辑选择。
- 文件、目录、整仓暂存/取消、丢弃、stash 创建/已有 stash 操作可用；SCM 列表/树模式、多仓库、分支创建/选择/tracking/安全删除、sync 可用且目标明确。
- 提交框可编辑、每仓库草稿持久化且失败保留；已有 Unknown 记录可在工作台内显式核对恢复。
- 只读预览复用来源高亮/行号/换行/选择复制、Markdown、图片、可选视频封面；文档可固定/切换，不启动第二 TUI 或接管其他窗格。
- 左右/首尾/翻页导航、鼠标快捷动作、Git footer、产品状态恢复、自有宿主快捷入口可达；图标/颜色/目录/装饰等设置符合实际生效语义。
- 顶部仅一行同层标题，无绝对路径挤占内容；80 列和长中文文件名不重叠；布局与鼠标命中使用同一矩形。
- Engine 真实临时仓库、TUI 事件与渲染、私有 PTY、打包安装测试覆盖上述行为；再执行完整 workspace、来源 UI 与三平台 CI，最后发布并验证全部附件。

## 任务图与集成

任务以 GitHub 子 issue 和原生阻塞关系跟踪，默认标签配置不变。K1 搜索/历史、K2 编辑、K3 Git、K4 刷新/顶部可独立开始；K5 完整预览依赖 K1/K2；K6 其余交互持久化依赖 K3/K4/K5；K7 集成与发布依赖全部实现。
