# 移除任务管理与后台编排

用户确认不再需要任务后端和相关引用。移除后端入口、四个专属底层 crate、任务 CLI、看板按钮和快捷键、完整工作台任务页、调度控制、插件事件 hooks、专属测试夹具与来源归档。

根 workspace 保留 Core、Engine、TUI、CLI、Code 五个包，所有平台只发行主程序。README、构建、归档、CI、许可证清单和安装 smoke 与当前范围一致，不再规划任务模块迁移。

文件、搜索、编辑、Git、Diff、评论、Agent 绑定与审查发送保持可用。Git 仍使用的操作日志与核对记录独立到 Engine 的 `operations` 模块。保留独立插件的隔离保护及当前产品安装失败恢复和回滚，不删除用户已有资料。

本决策替代 ADR-0001 中任务模块及独立后台入口的部分；原始规格与已发布更新日志保留历史事实。
